## Request
The task Activity is the most important screen: the person reviews the plan of the agent there. In the board split it was a side panel, and on a Galaxy Fold the task was smaller than on the phone. The phone layout must be the same as the desktop layout.

## Decision
1. A task opens as the task page, at each window width, on the desktop and on Android. The desktop board split and the Android third pane (Session) are removed. Inbox, knowledge, devices and the task folder keep their list and detail.
2. The task page is the same on both apps: Back, the key, the project, the state chips, "<i> of <n> need you" with Previous and Next (Inbox order), "Show list", the actions menu, the title, the stage bar; then the tabs.
3. "Show list" shows a task list of 300 px on the left. It shows only when the task page is 700 px (dp) or wider.
4. From 1,000 px (dp) of task page width, Properties is a 280 px right panel. Below it, Properties is a tab.
5. The content of the Activity and Session tabs and the message box have a maximum width of 840 px (dp) and are centred.
6. A long gate text shows its start and "Show more". "Show more" shows the full text in the page, with no scroll box of its own.
7. The decisions of a gate with "Request changes" are radio groups. A pick that differs makes the main button "Send my choices", which sends "Request changes" with the picks as the comment.
8. Only the platform differs: the control height (36 px desktop, 48 dp Android), the font and the app navigation (sidebar, bottom bar, rail, drawer).

## Reasons
- The plan and the decisions need the width; a list next to them takes it away.
- One page on both apps means one spec, one set of tests and one mental model for the person.
- "Show list" and the need-you arrows keep the fast switch between tasks that the split gave.
- 840 px keeps about 90 characters a line, so a wide window does not give long lines.
- The phone already had 48 dp touch targets; a 48 dp control height makes a field and its button one height.

## Not in this decision
- The Files tab on Android (a separate change).
- A live terminal on Android: the phone keeps the snapshot.
