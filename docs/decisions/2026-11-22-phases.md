# Decision: release phases

| Item | Value |
|---|---|
| Date | 2026-11-22 |
| Status | Accepted by the product owner |
| Replaces | The phase plans in PRD v0.5 to v0.7 (phase 1a, 1b, 2) |

## Decision
| Phase | Scope |
|---|---|
| Phase 1 (now) | Workspaces, projects, tasks, board, the task loop with gates, agents and sessions (Claude Code), continuity, knowledge, test slots, the `aw` CLI and skill, devices (local main device, optional 24/7 remote device, phone). Data in files: YAML documents and JSON Lines logs with a schema. Sync between the devices with built-in Syncthing. No relay. No sharing with People. No signals. |
| Phase 2 | Cloudflare R2 (backup, artifacts, sync when devices are not online together), the relay (iroh, `2026-11-22-relay-transport.md`), People and sharing, sources, subscriptions and signals, Send, the plugin marketplace, and all other items that PRD v0.7 planned for phase 1. |
| Phase 3 | The items that PRD v0.7 planned for phase 2: vault, schedules, meetings, canvas, more agents, more sources, Google Drive storage, vector and graph knowledge storage. |

## Rules
1. The clickable prototype v0.4+ shows the destination of AW (all phases). It stays as the target.
2. A separate, simple prototype shows phase 1 only.
3. Phase 1 must use the structure of the final architecture: the same data model, the same module boundaries and the same interfaces. Phase 2 adds parts. It does not rewrite phase 1.
