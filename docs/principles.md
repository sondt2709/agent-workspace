# Agent Workspace — Principles

Humans and agents obey these principles in each design, each line of code and each task. When a decision does not agree with a principle, the principle wins.

1. **Manage agents' work remotely.** You can do each human action from the phone. The apps are remote controls. When you close them, no work stops.
2. **Start on your computer, keep working forever.** You install AW on your local device, and it works with that device only. Add an optional 24/7 remote device, and the agents keep working while your laptop is closed. The work continues after a reboot, a crash, an update or a usage limit. A stop always shows its cause and when the work continues.
3. **Agents get knowledge and keep it.** Each task makes the next task better. The knowledge has a full history, undo and a backup.
4. **The human decides, the agent works.** An agent waits for you only at a gate. A gate shows the question, the evidence and the effect of each answer.
5. **You own all of it.** Your devices sync directly with each other. Your own storage and relay are optional; they add backup, live sync and sharing. No central AW service keeps your data.
6. **Connect first, then share.** People connect with each other first. Then their relays connect and share tasks, end-to-end encrypted.
7. **Evidence, not status.** Show the proof: the terminal line, the test report, the video. When there is no fresh proof, say "No recent update".
8. **Keep the original words.** Each agent that works on a task can read the original messages between the human and the agents, not only a summary. This prevents a misunderstanding.
9. **Nothing silent, nothing locked in.** Each change is visible and can be undone. Formats are open. Each vendor is a plugin.

## Design test
Before you add or change something, answer each question. When an answer is "no", change the design.
1. Can I do it from the phone?
2. Does it work with only my local device? With a remote device, does it work when my laptop is closed?
3. Does the work continue after a reboot, an update or a usage limit?
4. Does the agent keep what it learned?
5. Does it work with only my own devices?
