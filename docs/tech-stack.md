Rules for this list:
1. Use free or low-cost parts. Phase 1 needs no cloud account.
2. The project runs no service that keeps user data (principle 5).
3. Keep each vendor behind a plugin or an adapter (`decisions/2026-11-22-modules.md`).
4. Each part on a computer must run unattended as a service and survive a reboot.
5. Pin each version exactly in the lockfile or the version file. CI checks the pins. The "Choice" column gives the newest line on 2026-11-22. The pin is the newest release that is at least 7 days old on the install date (2.6). So the pin can be one line lower, for example `@tanstack/react-query` 5.107 until 2026-11-24.
6. Use a maintained library for each job outside the AW core (section 2, `engineering-rules.md` 4.8 to 4.12).

## 2. Libraries
AW writes its own code only for its core: the file model and merge, the ownership rules, the HLC, the Syncthing REST client logic, the session launcher and safe delivery, and the gate logic. A maintained library does each other job (`engineering-rules.md` 4.8 to 4.12). "Used in our other projects" marks a library that the maintainers already use. A library that fails a criterion has a row in `engineering-rules.md` 12. The rows for axios (2.3), TanStack Query, Redux Toolkit and `react-router` (2.4) answer the product owner's request. `prd.md` 13 lists the choices that wait for the owner.

## 4. Not used, and why
| Tool | Reason |
|---|---|
| NAT traversal (UPnP, NAT-PMP); a first start with the default config | It opens a port on the router (`prd.md` RMT-07). The default config did this within 33 s. |
| The Syncthing completion percentage as the sync state | It shows 100 % while a peer is offline (ST8), and before a scan. |
| The Syncthing connection state as presence | A frozen laptop still showed as connected. AW uses heartbeat events. |
| Copying the Android fork's code; Firebase Auth and Firestore | The fork's Java files are MPL-2.0. Firebase popups fail in Electron, and the files are the store. |
| Claude Code background sessions (`--bg`) in P1 | Research preview, no usage-limit wait, no boot service. A P3 session host. |
| A LaunchAgent on a headless Mac | Starts only after a GUI login. |
| Python or Go linters in this repository | AW has no Python or Go source. CI builds the upstream Syncthing Go code at a pinned tag and does not lint it. |
