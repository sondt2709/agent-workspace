# End-to-end tests

The Docker suite (`task e2e`, `src/*.docker.test.ts`) starts the 2 devices of `compose.yaml`. To run it next to another run on the same computer, set `AW_E2E_PROJECT` (the compose project name, default `aw-sync-e2e`) and `AW_E2E_IMAGE_TAG` (the image tag, default `local`). Example: `AW_E2E_PROJECT=aw-task-keys AW_E2E_IMAGE_TAG=task-keys pnpm --filter @aw/e2e test:docker`.

The tests that need a local app are opt-in (`docs/engineering-rules.md` 7.1.7). Each one prints "skipped: <tool> not installed" when the tool is missing. The real-device check (7.5.15) runs them.

| Test                                                                        | Needs                                        | How to run                                                                                                                                                                                                                                                                                                                                                                                              |
| --------------------------------------------------------------------------- | -------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Sessions with tmux and the fake agent (`daemon/src/sessions/*.e2e.test.ts`) | tmux 3.x                                     | `cd daemon && pnpm exec vitest run src/sessions`. `AW_E2E_TMUX` selects the tmux binary; a `tmux` in a `/.orca/` folder is skipped. Runs in `task check`.                                                                                                                                                                                                                                               |
| Real Claude Code session                                                    | `claude` 2.1.319 or later with a login, tmux | Start awd with `AW_CLAUDE_MODEL=haiku`, bind a checkout in `tasks/devices/<device>/bindings.yaml`, and assign a task to `claude@<device>`. Never in CI: it uses the paid model. Check that the plugin loads, `aw ask` opens the gate, an answer from another device reaches the session, and `--resume` after `kill -9` of claude keeps the session id.                                                 |
| Orca session host (`daemon/src/sessions/orca.e2e.test.ts`)                  | Orca 1.4.257 or later, `AW_E2E_ORCA=1`       | Without `AW_E2E_ORCA` the test runs with the fake Orca CLI in `task check`. With `AW_E2E_ORCA=1`, set `AW_ORCA` to a wrapper that runs the Orca CLI with `ORCA_USER_DATA_PATH` of a private runtime (`orca-ide serve --port <p> --bind 127.0.0.1 --no-pairing`), and `AW_E2E_ORCA_STOP`/`AW_E2E_ORCA_START` to the shell commands that stop and start that runtime. Never use the Orca app of a person. |
